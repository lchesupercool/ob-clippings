# 5.2 Tuple 结构

表页中的 heap tuple 分为两类：普通数据 tuple 和 TOAST tuple。本节只描述普通 tuple。

一个 heap tuple 由三部分组成：HeapTupleHeaderData 结构、==NULL bitmap==，以及用户数据（图 5.2）。

![](https://www.interdb.jp/pg/pgsql05/fig-5-02.png)

图 5.2. Tuple 结构。

HeapTupleHeaderData 结构的定义位于 `src/include/access/htup_details.h`。

`HeapTupleHeaderData` 结构包含七个字段，但后续章节中只会用到其中的四个：

- **t\_xmin** 保存插入该 tuple 的事务的 txid。
- **t\_xmax** 保存删除或更新该 tuple 的事务的 txid。
	如果该 tuple 未被删除或更新，==t\_xmax 会被置为 0==，表示 INVALID。
- **t\_cid** 保存 command id（cid），也就是在当前事务内本条命令执行之前已经执行过的 SQL 命令数量，从 0 开始计数。
	举个例子，假设我们在同一个事务里执行三条 INSERT 命令：'BEGIN; INSERT; INSERT; INSERT; COMMIT;'。如果第一条命令插入了这个 tuple，t\_cid 会被置为 0；如果第二条命令插入了这个 tuple，t\_cid 会被置为 1，依此类推。
- **t\_ctid** 保存 tuple identifier（tid），指向该 tuple 自身或指向一个新的 tuple。
	tid 的说明见 `Section 1.3`，用于在表中唯一标识一个 tuple。
	当该 tuple 被更新时，它的 t\_ctid 会指向新的 tuple；否则，t\_ctid 指向它自己。

```c
typedef struct HeapTupleFields
{
        TransactionId t_xmin;           /* inserting xact ID */
        TransactionId t_xmax;              /* deleting or locking xact ID */

        union
        {
                CommandId       t_cid;     /* inserting or deleting command ID, or both */
                TransactionId     t_xvac;    /* old-style VACUUM FULL xact ID */
        } t_field3;
} HeapTupleFields;

typedef struct DatumTupleFields
{
        int32          datum_len_;          /* varlena header (do not touch directly!) */
        int32          datum_typmod;           /* -1, or identifier of a record type */
        Oid            datum_typeid;           /* composite type OID, or RECORDOID */

        /*
         * Note: field ordering is chosen with thought that Oid might someday
         * widen to 64 bits.
         */
} DatumTupleFields;

typedef struct HeapTupleHeaderData
{
        union
        {
                HeapTupleFields t_heap;
                DatumTupleFields t_datum;
        } t_choice;

        ItemPointerData t_ctid;         /* current TID of this or newer tuple */

        /* Fields below here must match MinimalTupleData! */
        uint16          t_infomask2;    /* number of attributes + various flags */
        uint16          t_infomask;     /* various flag bits, see below */
        uint8           t_hoff;         /* sizeof header incl. bitmap, padding */
        /* ^ - 23 bytes - ^ */
/* bitmap of NULLs -- VARIABLE LENGTH */

        /* MORE DATA FOLLOWS AT END OF STRUCT */
} HeapTupleHeaderData;

typedef HeapTupleHeaderData *HeapTupleHeader;
```
