# 如何构建一个无需你做任何事、每天都会变得更聪明的 Obsidian 知识库

来源: [X 上的 CyrilXBT](https://x.com/cyrilxbt/status/2052235121416188114?s=52)  
作者: CyrilXBT (@cyrilXBT)  
发布时间: 2026-05-07 11:52

![](../../assets/x-cyrilxbt-2052235121416188114/x-cyrilxbt-2052235121416188114-01.jpg)

你读过的每一篇文章。你保存的每一条推文。你录下的每一条语音笔记。所有这些都会自动流入。Claude 负责把点连起来。你负责收获洞见。

大多数人把自己的 Obsidian vault 当成文件柜。他们把东西放进去。却再也不把任何东西取出来。六个月后，他们拥有了一个组织得很漂亮的信息档案库，但这些信息他们已经完全忘记，也从未采取行动。

本指南要构建的是完全不同的东西。不是一个由你不断添加内容的 vault。而是一个会反过来添加到你身上的 vault。一个系统，让你消费的每一条信息自动流入其中，Claude 浮现出你错过的连接，而洞见会在你不做任何额外工作的情况下每天复利增长。

第二大脑和死亡档案之间的区别只有一件事：反馈。只进去却从不出来的信息，不是知识系统。它只是一个文件夹整理得不错的墓地。本指南构建的反馈回路，会把你的 vault 从存储系统变成思考伙伴。

## 为什么大多数知识系统会失败

第二大脑的承诺是，你再也不会丢失任何好想法。对大多数人来说，现实是他们花三个小时搭出一个漂亮的文件夹结构，添加内容两周，然后就彻底不再打开这个应用，因为从中从未返回过任何有用的东西。

失败模式总是相同的。系统是为输入而设计的。没有人为输出而设计。你捕获了一切。却什么也没有检索回来。vault 在增长。你的思考没有。

发生这种情况有三个具体原因，而每一个都可以修复。

第一：捕获摩擦。如果把某个东西加入你的 vault 需要超过 10 秒的手动努力，那么在任何真实的认知负荷下，你都会停止这样做。大多数人的捕获工作流包含复制、粘贴、打标签、分类和总结——而这一切发生在他们甚至还没有处理刚刚读到的内容之前。当摩擦高到一定程度，习惯就会断裂。

第二：没有连接层。大多数 vault 都是孤立笔记的集合。每篇文章存在自己的文件里。每个想法坐落在自己的文件夹里。没有任何机制会横跨全部内容并说：你三月保存的这个东西，正好直接连接到你今天正在处理的问题。没有这一层，vault 就是一座没有搜索功能的图书馆。

第三：没有返回的理由。如果你的 vault 不把洞见推回给你，你就必须记得去拉取它们。没有人记得。vault 变成了你偶尔添加内容、只有在主动寻找某个特定东西时才打开的地方。那不是思考伙伴。那是书签工具。

一个从不回话的第二大脑不是第二大脑。它是一种非常有条理地遗忘事物的方式。

本指南构建的系统解决了这三个问题。捕获是自动的——你永远不需要手动添加任何东西。连接是 Claude 的工作——它跨越所有内容阅读并浮现重要之物。返回被内置进日常仪式——vault 每天早晨在你没有请求的情况下向你简报。

## 架构：协同工作的四层

在接触任何工具之前，先理解这个四层结构。这个系统中的每个软件都只服务于一个功能。没有重叠。一切都朝一个方向流动。

第一层是捕获。这包括所有无需你手动输入任何内容就把信息带入系统的工具。Readwise 用于文章和高亮。Airr 用于播客片段。Whisper 用于语音笔记。一个专用 Telegram bot 用于从手机快速保存。这一层中的任何东西都不要求你分类、打标签或总结。原始信息进入。仅此而已。

第二层是流水线。N8N 自动化会监听每个捕获来源，并把新内容路由到你 Obsidian vault 中的正确位置。不需要手动归档。不需要复制粘贴。一条新的文章高亮出现在 Readwise 中，几分钟内它就会作为一个格式化的 markdown 文件进入你的 vault，并自动结构化好来源、日期和内容。

第三层是 Obsidian。vault 本身。你本地机器上的一组 markdown 文件夹。这是永久存储层。一切都住在这里。没有东西会被删除。vault 是你曾经消费并认为值得保存的一切内容的事实来源。

第四层是 Claude。这是运行在其他所有层之上的智能层。Claude 读取 vault。寻找连接。浮现模式。撰写每日简报。回答关于你自己思考的问题。正是这一层让 vault 成为思考伙伴，而不是档案库。

## 第一步：无摩擦的自动化捕获

捕获层只有一个工作：不向你索取任何东西地收集一切。捕获中的每一个摩擦点，都是你知识库中的未来缺口。一次性设置好。以后再也不用碰。

文章和高亮：Readwise 是书面内容捕获层的骨干。安装浏览器扩展。你读每篇文章时，高亮重要的句子。Readwise 会自动存储它们。你不需要做别的事。不总结。不打标签。高亮，然后继续。

Readwise 还可以连接 Kindle、Twitter 书签、Instapaper 和 Pocket。你在这些平台中保存的任何内容都会自动流入 Readwise。一个工具聚合一切。

播客和音频：Airr 让你通过摇晃手机来截取播客时刻。片段的转录会自动保存。对于任何更长的内容——会议、讲座、语音笔记——录下来并通过 Whisper 处理。粘贴音频文件，几秒内获得干净的转录文本。

从任何地方快速捕获：构建一个 Telegram bot，接受你发送给它的任何消息，并将其路由到你的 vault。开车时突然出现的想法。你想进一步思考的一条推文。对话中出现的一个问题。把它发给 bot。它会自动落入你 vault 的 inbox 文件夹。用 Claude Code 和 N8N 30 分钟就能构建完成。

N8N 工作流 — Telegram 到 Obsidian：

- 节点 1: Telegram Trigger → event: message → chat_id: your_bot_id
- 节点 2: Code（格式化笔记）→ filename: inbox/{{date}}-quick-capture.md → content: # Quick Capture / {{message}} / Source: Telegram / Date: {{date}}
- 节点 3: Write File 到 Obsidian vault → path: /your-vault/inbox/ → operation: create

## 第二步：能够扩展的 vault 结构

你的 vault 文件夹结构决定了 Claude 能多好地导航它。不要过度设计。五个文件夹。这就是全部结构。

Inbox — 一切都先落在这里。未处理。原始。所有自动捕获在被归档前的暂存区。

Notes — 处理后的高亮、文章、播客片段。每个来源一个文件。由 N8N 流水线自动格式化。

Ideas — 你自己的思考。快速捕获。观察。转录后的语音笔记。你大脑的输出，而不是其他人的输入。

Projects — 活跃工作。每个项目一个文件夹。当你请求项目特定的上下文或决策时，Claude 会读取这些内容。

CLAUDE.md — 指令层。Claude 在每个会话中首先读取的文件。告诉它你是谁、你正在做什么，以及你希望它为你做什么。

这种简洁是有意为之的。每一种复杂的文件夹结构最终都会在自身重量下崩塌，因为你会不再知道某个东西应该属于哪个文件夹，捕获摩擦会上升，直到系统破裂。五个文件夹。一条规则：拿不准时，放进 inbox。

## 第三步：让一切运转起来的 CLAUDE.md 文件

这是整个系统中最重要的文件。没有它，Claude 每次会话都会冷启动——没有关于你是谁、你正在做什么、你想从 vault 中得到什么的上下文。有了它，Claude 就像一个已经阅读你的笔记数月的协作者。

CLAUDE.md 是你 vault 根目录中的一个 markdown 文件。Claude 会在每次会话开始时自动读取它。直接复制这个模板：

### 我是谁

姓名: [你的姓名]  
工作: [你做什么——请具体]  
重点: [你现在正努力变得更好的那一件事]  
2026 目标: [你正在推进的 3 个具体结果]

### 当前项目

活跃项目: [你现在正在构建或处理的内容]  
卡住的地方: [你最需要思考帮助的地方]  
下一个里程碑: [当前 sprint 中“完成”是什么样子]

### 这个 vault 如何工作

Inbox: /inbox — 未处理的捕获，先归档到这里  
Notes: /notes — 处理后的文章、高亮、研究  
Ideas: /ideas — 我自己的思考和观察  
Projects: /projects — 活跃工作文件夹

### 我希望你做什么

- 浮现我还没有看到的连接
- 在同意我的观点之前挑战我的假设
- 当我问应该专注于什么时——从 vault 上下文回答，而不是泛泛而谈
- 当我相信的某件事与我之前保存的某件事相矛盾时提醒我

### 我正在阅读和思考什么

[每周更新这里——当前痴迷的主题、活跃问题、让你困惑的事情]

每周一早晨更新 Current Projects 和 What I Am Reading 部分。五分钟。这个单一习惯会随着你的工作演化而保持 Claude 的上下文准确。陈旧的 CLAUDE.md 会产生陈旧的回答。

## 第四步：自动运行的每日简报

每天早晨，在你打开任何应用之前，vault 会向你做简报。昨夜发现的新连接。本周捕获内容中的模式。基于你一直在阅读的一切，今天值得思考的那个问题。

你不需要请求这份简报。它通过 N8N 按计划自动运行。当你坐下来工作时，它已经在你的 inbox 文件夹里等着了。

把这个 prompt 直接复制到你的 N8N Claude 节点中：

```text
你正在阅读我的 Obsidian 知识库。读取过去 24 小时 /inbox 中的所有内容，以及过去 7 天 /notes 中的所有内容。

然后做三件事：
CONNECTIONS — 找出最近捕获内容与较旧笔记之间 3 个最有趣、我可能还没有注意到的连接。要具体。引用相关段落。
PATTERN — 识别我本周阅读的一切内容中的一个模式。即使我没有明确说出来，我的大脑显然正在处理什么？
QUESTION — 基于你识别出的模式，给我一个今天值得静坐思考的问题。不是任务。是问题。

将其写成一个适合 Obsidian 的干净 markdown 文件。保存到 /inbox/brief-{{date}}.md
```

设置它在每个工作日早上 6 点运行。在打开其他任何东西之前先读它。

## 第五步：每周综合

每周一次，运行一次更深入的综合。十五分钟。和 Claude 坐下来谈谈 vault 一直在朝什么方向构建。

复制这个 prompt：

```text
读取我的整个 Obsidian vault。重点关注过去 7 天添加的所有内容。

我想要四件事：
EMERGING THESIS — 我正在朝什么想法构建，但还没有明确陈述出来？我的思考中正在形成什么立场？
CONTRADICTIONS — 我最近保存了哪些与我过去相信的东西相矛盾的内容？从我自己的笔记中展示双方。
KNOWLEDGE GAPS — 基于我正在阅读和思考的内容，我显然没有阅读但应该阅读什么？缺少什么视角？
ONE ACTION — 考虑这个 vault 中的一切，本周我可以做或思考的单个最高杠杆事项是什么？

直接一点。挑战我。不要总结我已经知道的东西。
```

综合会话是真正发生复利的地方。每日简报浮现连接。每周综合构建论点。经过六个月的每周会话，你会拥有一份关于自己思考如何演化的记录——你曾持有并改变过的每个假设，每个从小想法成长为行动对象的想法。

## 没有人谈论的复利效应

一个月时，vault 感觉像一个有用的工具。你保存得更多，丢失的想法更少，每日简报偶尔会浮现一些有趣的东西。

三个月时，感觉开始不同。Claude 开始把第一个月的东西和第三个月的东西连接起来。你向它询问一个当前问题，它会找到八周前那条你已经完全忘记的相关笔记。vault 知道一些关于你思考的事情，而这些事情你并没有有意识地记得。

六个月时，它完全变成另一种东西。你拥有自己曾持有并改变过的每个信念的记录。每个你曾长期面对的问题，以及最终浮现出的答案。每个在你有意识地把它识别为痴迷之前，就已经出现在你阅读中的模式。

经历六个月后你拥有的 AI，不再是你最初开始时的那个。它在你忙着生活的时候一直在阅读你的大脑。

这就是你自身思考的复利。大多数知识从不复利，因为它们孤立地躺着。这个系统会自动建立这些连接。你消费的每个想法都会加入一个不断增长的想法网络，Claude 可以代表你在其中导航。

比你晚六个月开始这个系统的竞争者，不只是落后于设置。他们落后的是六个月的连接、模式和综合，而这些会让系统真正理解你特定的思考方式。这个差距无法通过更努力工作来弥合。它只能通过更早开始来弥合。

## 完整设置顺序

01 — 安装 Obsidian，并创建五个文件夹结构：Inbox、Notes、Ideas、Projects，以及根目录中的 CLAUDE.md。不要添加任何其他文件夹。简单开始，让结构从真实使用中演化。

02 — 将 Readwise 连接到你的 vault。Readwise 有原生 Obsidian 集成。启用它。你在任何地方做出的每条高亮都会自动作为格式化 markdown 文件出现在 Notes 文件夹中。

03 — 用 N8N 构建 Telegram 捕获 bot。使用上面的工作流。耗时 30 分钟。一旦运行，它会在你余生中处理来自手机的每一次快速捕获。

04 — 编写你的 CLAUDE.md 文件。使用上面的模板。具体而诚实。Claude 输出的质量与你在这个文件中提供的上下文质量成正比。

05 — 在 N8N 中设置每日简报自动化。安排简报 prompt 在每个工作日早上 6 点运行。输出进入你的 inbox 文件夹。在打开任何其他东西之前阅读它。

06 — 每周一留出 15 分钟做每周综合。现在就放进日历。这是复利真正发生的会话。不要因为第二周 vault 感觉太空而跳过它。vault 永远不会空到找不到值得思考的东西。

## 从五条笔记开始

人们从未构建这个系统的最常见原因，是它感觉像是一次性要设置太多东西。

从更小处开始。今天，把五条笔记放进 Obsidian。任何东西——五篇你一直想读的文章、五个一直在你脑中的想法、五个你反复回到的问题。把 Claude 连接到那个文件夹。让它在这五条笔记之间寻找连接。

它会发现你错过的东西。它总是会。那个时刻——当 Claude 浮现出两个你以为完全无关的东西之间的连接时——就是这个系统不再只是一个概念，而开始成为你每天都想喂养的东西的时刻。

今晚从五条笔记开始。剩下的交给 vault。
